The first one-photo build downloads the TripoSR model (about 485 MB) once; it is kept in this browser.

Download the one-photo model?

TripoSR builds a shape from a single photo. Its model is about 485 MB, downloaded once from Hugging Face and kept in this browser for next time. Your photo stays on this computer.

Licence: MIT (TripoSR) and Apache-2.0 (its image encoder). About the model files. Runs fastest in Chrome or Edge with WebGPU.
