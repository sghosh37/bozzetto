bozzetto

bot-SET-toh, noun, Italian. Plural bozzetti, from bozza, a rough draft.

The small, rough model a sculptor shapes in clay or wax to settle the form before the real work.

This Bozzetto makes one from photos of a real object: a closed 3D mesh at real size, ready to refine and finish in Blender.

Try it in your browser Install the desktop app

From photos to Blender

  1. Photograph the object

    A single clear photo, a full turn on a turntable against a plain backdrop, or a slow video circling it.

  2. Build the shape

    Bozzetto picks a scanning method for your photos and your computer, and builds the mesh right there. Nothing is uploaded.

  3. Refine it in Blender

    Open the OBJ: it is in millimetres, Y up, with the base at zero. Sculpt, fix and detail from there.

In the browser or on your computer

The browser version needs nothing installed and handles a single photo or a turntable shoot. The desktop app adds the methods that need more computing power.

Scanning methods

Each suits a different kind of shoot. The app chooses one for you and lets you pick another.

Turntable silhouette

Carves away everything outside the object’s outline in each photo of a full turn. Fast and dependable; hollows and dents are filled in.

Browser and desktop

TripoSR

An AI model that builds a whole shape from one photo, guessing the sides it can’t see. Downloads once: about 1.7 GB on the desktop, a 485 MB compressed copy in the browser.

Browser and desktop

Apple Object Capture

Apple’s photogrammetry on a Mac, from 20 or more photos all round. Detailed, with colour.

Coming next (Mac)

COLMAP + OpenMVS

Open-source photogrammetry on any computer, best with an NVIDIA graphics card.

Install the desktop app

Until the installers are ready, install from the source code. You need Python 3.10 or newer.

git clone https://github.com/sghosh37/3d-scan.git
cd 3d-scan
python -m venv .venv
.venv\Scripts\activate          # macOS or Linux: source .venv/bin/activate
pip install -e .                # the app and the silhouette method
pip install -e ".[triposr]"     # optional: the one-photo method
bozzetto                        # opens the window

Run it on your own computer

The browser version also works offline from a copy of the code. Browsers only run it from a web address, so start a small local server in the folder:

cd 3d-scan
python -m http.server 8000
# then open http://localhost:8000/web/

The command line is bozzetto-cli photos/ out/ --height-mm 82.
